# 浏览器回归测试

运行 `node tests/run-link-modal.mjs`，然后在浏览器打开终端显示的本地地址。
页面自动运行链接编辑器的真实浏览器测试，显示每个场景的结果。终端通过 Vite 本地连接收集结果，全部通过时退出码为 0，失败时为 1。

测试直接挂载 `LinkModal`，点击获取图标并通过 `requestSubmit()` 执行浏览器原生表单校验，验证保存回调及书签数据。覆盖站内图标路径、外部 URL、空图标、无效输入及 R2 图标；保存回调使用本地替身，不读写线上数据。该页面不包含在生产构建中。

标题 AI 补全测试使用模拟响应，覆盖三种 AI 服务、空标题补全并保存、缺少 URL / API Key、失败保留原标题，以及修改输入、关闭窗口或保存后忽略过期响应。不会调用真实 AI 服务。
