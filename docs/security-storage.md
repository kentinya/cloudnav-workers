# 安全与存储说明

设置窗口以一个请求提交全部配置。后端通过 R2 的 `__cloudnav/config` 对象及条件写入一次发布完整设置；并发保存冲突返回 `409`，缺少版本返回 `428`。界面只在收到成功结果及新版本后提示保存成功。网络结果不确定时，应重新打开设置确认云端数据。

升级时会读取旧 KV `config` 和 `config:*`，保留原来的配置覆盖关系及其他设置字段；首次保存后以 R2 快照为准。旧客户端的单项设置接口仍经过同一个原子保存路径。不要手动删除 R2 中的 `__cloudnav/` 内部对象，否则可能丢失设置、版本、会话撤销记录或限流状态。

密码验证使用十分钟固定窗口：管理员每个客户端最多 10 次、全站最多 100 次；私密分类每个客户端最多 20 次、全站最多 200 次。分类验证共用预算，切换分类 ID 不会重置计数。客户端取 Cloudflare 提供的 `CF-Connecting-IP`，不信任 `X-Forwarded-For`；本地缺少该头时共用一个客户端。成功和失败的密码尝试都计数，已验证的管理员 Token 不消耗密码预算，退出登录也不会重置预算。

计数存储在两个有固定名称的 R2 对象中，以条件写入防止并发绕过，不为每个 IP 永久创建对象。记录只保存客户端地址摘要。触发限制返回 `429` 和 `Retry-After`；计数存储不可用时返回 `503`，不继续验证密码。旧扩展直接通过请求头发送管理员密码的方式也适用该限制。

图标文件上限为 2 MiB，与现有前端限制一致；multipart 请求额外允许 64 KiB 的表单开销。后端按实际读取的字节限量，不能用缺失或伪造的 `Content-Length` 绕过。文件类型依据内容签名判断，忽略文件名扩展名和声称的 MIME；支持 PNG、JPEG、GIF、ICO、WebP、BMP、AVIF 及静态 SVG。SVG 拒绝脚本、事件、外部资源和活动内容，返回图标时附加 `nosniff` 与限制性 CSP。

远程图标仅支持无用户名和密码的 HTTP/HTTPS URL，端口限 80/443。阻止本机、内网、链路本地、保留 IP 和本地域名，并检查 DNS 的 IPv4/IPv6 结果。最多跟随三次重定向，每次重新验证 URL 和 DNS；禁止 HTTPS 降级，跨域跳转移除凭据请求头。自定义图标 API 的 POST 请求不跟随重定向，其 JSON 响应上限为 64 KiB。

每个远程请求的十秒期限涵盖 DNS、连接、重定向和完整响应体。上传转存、公开图标代理、域名图标缓存和历史图标缓存使用同一套检查。保留 Wrangler 的 `global_fetch_strictly_public` 标志，使同区请求经过公开入口，避免绕过 Cloudflare 安全设置访问源站。使用 fake-IP DNS 的本地代理可能把公网域名解析到 `198.18.0.0/15` 等保留地址；这类地址也会被拒绝。

运行 `pnpm test:worker` 验证设置失败与并发一致性、两类密码限流、图标内容校验、SSRF、重定向、超时及原有导航和备份功能；使用 `pnpm build` 和 `pnpm exec wrangler deploy --dry-run` 检查构建，无需部署。
